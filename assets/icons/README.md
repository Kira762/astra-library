# Astra icon catalog

All packs can be mixed in one window. No window-wide pack option is needed.

Use `icon = "pack:name"` to select an exact icon. Copy the name from the catalogs below.
Bare names search lucide → material → tabler → phosphor → heroicons → feather.
Names are case-sensitive. Pack tables are loaded only when looked up.

Previews use the repository's PNG files (many are white on transparent; use GitHub dark mode).

- [Lucide — 1776 icons](guides/lucide.md)
- [Material — 1133 icons](guides/material.md)
- [Tabler — 5130 icons](guides/tabler.md)
- [Phosphor — 1512 icons](guides/phosphor.md)
- [Heroicons — 648 icons](guides/heroicons.md)
- [Feather — 287 icons](guides/feather.md)
